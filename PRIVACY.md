# QuickRead AI Privacy Policy

Last updated: June 6, 2026

QuickRead AI is a browser extension that summarizes the current web page or selected text after the user opens the extension.

## Data QuickRead AI Handles

QuickRead AI may handle the following data:

- Web page title, URL, metadata, selected text, and extracted page content.
- API provider, API base URL, model name, output settings, and summary cache.
- API key entered by the user.

## How Data Is Used

QuickRead AI uses page content only to generate summaries requested by the user. The extension sends the extracted page content directly from the user's browser to the API provider selected in the extension settings, such as OpenAI-compatible services or a custom provider configured by the user.

QuickRead AI does not operate a developer-owned backend service for collecting, storing, or analyzing user page content.

## Storage

Settings, API keys, onboarding state, and optional cached summaries are stored locally in the user's browser through Chrome storage. Users can clear connection settings from the extension settings page.

## Sharing

QuickRead AI does not sell user data, use user data for advertising, or share user data for unrelated purposes.

User content is transferred only as needed to the API provider selected or configured by the user so the extension can generate the requested summary. The selected provider's own privacy policy and terms apply to that processing.

## Permissions

- `storage`: Saves local settings, API key, onboarding state, and optional summary cache.
- `activeTab`: Reads the current tab only after the user opens the extension.
- `scripting`: Injects the content extraction script into the current tab after user action.
- API host permissions: Sends summary requests to the selected AI provider.
- Optional host permissions: Allows the user to connect to a custom API provider origin.

## Limited Use

QuickRead AI uses browser data only to provide or improve the user-facing page summarization feature. It does not use page content, browsing activity, or API keys for personalized advertising, retargeting, sale of data, or unrelated analytics.

## Security

QuickRead AI uses HTTPS for supported remote API providers. Plain HTTP custom API URLs are allowed only for localhost or 127.0.0.1 during local development.
